# ماسح السيولة والإيجابية للأسهم والعملات الرقمية

## التشغيل

1. حمّل ZIP من GitHub وفك الضغط.
2. شغّل `install.bat` مرة واحدة.
3. شغّل `run.bat`.
4. افتح `http://localhost:8501`.
5. أدخل مفاتيح Alpaca داخل الشريط الجانبي لتحليل الأسهم.

## التبويبات

- **الأسهم الأمريكية:** تستخدم Alpaca، وتحتاج `ALPACA API Key` و`ALPACA Secret Key`.
- **العملات الرقمية:** تستخدم Binance Spot public API ولا تحتاج مفاتيح. استخدم رموز Binance مثل `BTCUSDT` و`ETHUSDT`، رمزًا واحدًا في كل سطر داخل `crypto_symbols.txt`.

كل قائمة مستقلة وبحد أقصى 100 رمز. يمكن تعديل الملفات أو رفع TXT/CSV من داخل اللوحة.

## التحليل

يتم جلب شموع Binance بدقيقة واحدة وتجميعها إلى شموع مكتملة مدتها دقيقتان، ثم مقارنة آخر شمعة مكتملة بالسابقة. تُحسب الحركة السعرية ونمو الحجم وقيمة التداول وRVOL وVWAP وEMA9 وEMA20 وRSI. يعرض التطبيق أفضل 5 عملات إيجابية وأفضل 5 عملات سالبة مرتبة للمتابعة المحتملة للشورت.

## تنبيه مهم

قائمة العملات السلبية ليست توصية بفتح صفقة بيع على المكشوف. تداول العقود الآجلة أو الهامش يحتاج حسابًا ومنصة تدعم ذلك، وإدارة مخاطر مناسبة. بيانات Binance المستخدمة هنا هي Spot العامة؛ لا يتم تنفيذ أي صفقات آليًا.

بيانات الأسهم المجانية عبر Alpaca IEX لا تمثل كامل السوق الأمريكي، وقد تكون تغطية premarket محدودة. مفاتيح Alpaca لا تُحفظ في GitHub.
