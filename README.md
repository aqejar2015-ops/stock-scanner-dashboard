# US Stock Pre-Rise Scanner

## التشغيل

1. حمّل ZIP وفك الضغط في مجلد جديد، وليس داخل مجلد نسخة قديمة.
2. شغّل `start_windows.bat`.
3. ستظهر خانة **API Key** في الشريط الجانبي داخل لوحة التحكم.
4. الصق مفتاح Polygon/Massive في خانة API Key واضغط Enter أو انقر خارجها.
5. لا تحتاج إلى إنشاء ملف `.env` بهذه الطريقة، ولا يتم حفظ المفتاح في GitHub.

يمكنك أيضاً استخدام ملف `.env` اختيارياً:

```dotenv
POLYGON_API_KEY=ضع_مفتاحك_هنا
```

## إعداد الأسهم

الأسهم الأساسية الثلاثة:

```text
GRML,IMCC,WHLR
```

أدخل الأسهم المراد فحصها، ثم اضبط الحد الأدنى للارتفاع وعدد الشموع.

> هذه أداة تشابه تاريخي وليست توصية مالية. توفر بيانات الدقيقتين يعتمد على خطة Polygon/Massive.
