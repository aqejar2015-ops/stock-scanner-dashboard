# ماسح السيولة والإيجابية للأسهم الأمريكية

## التشغيل

1. حمّل ZIP من GitHub وفك الضغط.
2. شغّل `install.bat` مرة واحدة.
3. شغّل `run.bat`.
4. افتح `http://localhost:8501`.
5. أدخل `ALPACA API Key` و`ALPACA Secret Key` مباشرة في الشريط الجانبي داخل لوحة التحكم.

يمكن كذلك وضع المفاتيح في ملف `.env`، لكن إدخالها من لوحة التحكم هو الطريقة الأسهل:

```env
ALPACA_API_KEY=your_key
ALPACA_SECRET_KEY=your_secret
ALPACA_FEED=iex
```

## إعداد الأسهم

عدّل `symbols.txt`، رمز واحد في كل سطر، بحد أقصى 100 سهم. ويمكن رفع ملف TXT أو CSV من داخل اللوحة.

## ملاحظات البيانات

الخطة المجانية `IEX` ليست SIP ولا تمثل كامل التداول الأمريكي، وقد تكون تغطية premarket محدودة لبعض الرموز. التطبيق يقارن السعر والسيولة مع آخر شمعة دقيقتين، ويستخدم RVOL وVWAP وEMA وRSI والسبريد لترتيب أفضل خمسة أسهم. النتائج تحليلية وليست توصية شراء أو بيع.

لا تضع ملف `.env` أو مفاتيحك داخل GitHub؛ الملف مستثنى عبر `.gitignore`.
