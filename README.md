# ماسح السيولة والإيجابية للأسهم الأمريكية

هذه النسخة تستخدم **Alpaca Market Data API** وتراقب حتى 100 رمز، مع تحديث افتراضي كل دقيقتين، ثم ترتب أفضل خمسة أسهم حسب تحسن السعر والسيولة والحجم النسبي وVWAP وEMA وRSI والسبريد عند توفره.

## التشغيل على Windows

1. من GitHub اختر **Code → Download ZIP** ثم فك الضغط.
2. شغل `install.bat`.
3. افتح `.env` وأدخل مفتاحي Alpaca:

```env
ALPACA_API_KEY=your_key
ALPACA_SECRET_KEY=your_secret
ALPACA_FEED=iex
```

4. عدل قائمة الأسهم في `symbols.txt`، رمز واحد في كل سطر، بحد أقصى 100.
5. شغل `run.bat` وافتح العنوان الذي يظهر، غالبًا `http://localhost:8501`.

## ملاحظات البيانات

الخطة المجانية `IEX` ليست SIP ولا تمثل كامل التداول الأمريكي، وقد تكون تغطية premarket محدودة لبعض الرموز. لذلك يستخدم التطبيق فلاتر للسعر والسيولة والسبريد ولا يعتبر ارتفاع الحجم مع انخفاض السعر إشارة إيجابية. النتائج ترتيب تحليلي وليست توصية شراء أو بيع.

لا تضع ملف `.env` أو مفاتيحك داخل GitHub؛ الملف مستثنى عبر `.gitignore`.
